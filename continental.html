The Challenge & Context

A highly technical digital signal processing (DSP) tool used by automotive engineers to test and tune vehicle audio for adverse conditions (noisy roads, bad weather).

The Problem:

  • Legacy Architecture: Built for raw efficiency with zero UX intervention.
  • High Error Rates: Complex feature additions led to frequent errors from new users, requiring constant specialist intervention.
  • Scaling Challenges: The tool was adopted by external partners, making steep learning curves a business liability.

Comments

Product Manager

Continental Team

Create an interface easy enough for a partner to learn, without slowing down a Continental expert.

Understanding the User & The Complexity

This is not a consumer app; it is a specialized workspace for users skilled in digital signal processing. The tool's primary functions include tuning audio via proprietary parameters, managing configuration files, and generating detailed change reports.

To address the prompt's core tension—balancing the needs of novices and experts—I defined two primary usage modes.

User Type Primary Need Design Strategy
New Users/Partners Step-by-step guidance, clear error prevention, and easy onboarding. Guided "Wizard" Mode: Simplifies complex workflows into digestible steps without overwhelming the user.
Expert Engineers Speed, density, and unrestricted access to all DSP parameters. Advanced Mode: Allows experts to bypass the wizard, utilizing streamlined UI and expandable menus to work efficiently.

Design Strategy & Execution

To bridge the gap between design and development, and to tame the growing complexity of the tool, a systematic approach was required.

  • Atomic Design System: Built a comprehensive component library from the ground up to ensure UI consistency across all software modules.
  • Seamless Developer Handoff: Delivered fully documented specifications via Adobe XD and Axure, making components easily inspectable for front-end developers.
  • Knowledge Transfer: Conducted dedicated KT sessions with Continental’s engineering team to smoothly transition ownership of the new design system.

A Refined, Purpose-Driven UI Overhaul

Every visual decision was tied back to usability and the physical environment in which the engineers worked (often inside vehicles with varying light conditions).

  • Variable Lighting Optimization: Adopted a strategic Blue primary color palette for all interactive elements, proven to offer the best contrast and visibility across unpredictable lighting environments.
  • Cognitive Load Reduction: Removed random, distracting colors that obscured text. Stripped away persistent text labels in favor of tooltips and an expandable sidebar, drastically reducing space wastage.
  • Bulletproof Iconography: Redesigned the entire icon suite, pairing them with micro-interactions.
